Welcome! This blog is built with [Astro](https://astro.build), and every
post is just a markdown file living in `data/blog/`.

To publish a new post, add a `.md` file to `data/blog/` with frontmatter for
`title`, `description`, and `pubDate` — no code changes required.

## Why markdown in `data/`

Keeping posts as plain markdown files makes them easy to write, review, and
version control independently of the site's code.
